 PARASY8 + POWER TOOLS - UNIFIED INSTALL GUIDE
================================================================

This is one unified loader. Do not install the older Parasy8 source and
the separate Power Tools Companion together; both try to own the same
Settings page.

INSTALL
  1. Remove the old Parasy8 source/module and the old Power Tools source/module.
  2. Add this package source using the URL supplied with this release.
  3. Install Parasy8 + Power Tools.
  4. Fully close and reopen 8SPINE.
  5. Open the Parasy8 Settings tab.
\WHAT YOU SHOULD SEE
  The existing Parasy8 page remains available with Export music, Debug,
  and Unpatch. It now also includes a Power Tools section with an Audio
  normalization row. Tap that row to apply compatible normalization settings.
\SCOPE
  This build does not bypass Premium, remove ads, alter DRM, or modify streams.
  Normalization applies only when the app exposes a compatible state store.
\================================================================

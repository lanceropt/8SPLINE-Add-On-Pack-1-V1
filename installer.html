Power Tools

One-tap installer for the 8SPINE app. Host source.json and power-tools.js in GitHub, then paste a raw URL below and tap a button. Open this page in Safari on your iPhone.

Deep link: eightspine://source?url=... - pastes the whole source (Power Tools) into Add Source. Recommended.
Deep link: eightspine://install?url=... - install just the module file. Paste the power-tools.js raw URL for this one.
  1. Open the GitHub repository in Safari and open source.json.
  2. Tap Raw and copy the raw URL.
  3. Paste the raw source.json URL above, then tap Add source to 8SPINE.
  4. The included source.json already points to the raw module file.
